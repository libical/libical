# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.0.x   | not supported      |
| 4.0.x   | supported          |

## Reporting a Vulnerability

Report vulnerabilities to our issue tracker at <https://github.com/libical/libical/issues>.

This is an open source project. Issues are worked as time allows and without
turn-around time guarantees.

Pull-requests (preferably to include regression testing) associated with the
vulnerability have the best chance of quick action.
